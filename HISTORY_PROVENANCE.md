# Source-history provenance

This git history was **reconstructed from user-supplied ZIP releases** in November 2026.
These are **not** the original development commits. All commits were created when the
history was rebuilt, without inventing individual past dates or original authors.
Commit bodies describe features confirmed in the supplied release source/README.

Historical snapshots deliberately omit actual `models.json`, `settings.json`,
runtime state, user logs and Android-project-specific benchmark prompts. Strings
containing machine-specific local paths were anonymised before every commit.
Therefore `git archive` of an old tag is **not** byte-identical to the ZIP release.
