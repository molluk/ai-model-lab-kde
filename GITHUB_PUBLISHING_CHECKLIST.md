# Перед публикацией на GitHub

1. Запустить GUI на CachyOS и проверить запуск выбранной модели в Pi и OpenCode.
2. В публичном дереве уже находятся обобщённые Android STB/VOD-промпты; проверить их ещё раз на отсутствие частных названий и данных. Приватные исходные промпты и fixtures проекта не публиковать.
3. Проверить `git status --short`, `git ls-files` и `git diff --cached --name-only`; не добавлять `data/`, `models.json`, `settings.json`, GGUF, токены и приватные исходники.
4. Заменить демо-названия и тексты, если они могут нарушать права владельцев моделей / компаний.
- Публичная история: лицензия PolyForm Noncommercial 1.0.0 во всех коммитах и тегах; ранее отдельно переданные копии могут иметь другие условия.
6. Запустить `python3 release_preflight.py` и `python3 -m unittest discover -s tests -v`.
7. Включить GitHub secret scanning / push protection; не загружать историю, файлы и токены из приватных сред.
8. Сначала опубликовать как **Alpha / experimental**, не обещать поддержку всех дистрибутивов и моделей.
