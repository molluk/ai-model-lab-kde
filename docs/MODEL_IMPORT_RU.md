# Импорт локальных GGUF: Censored + Uncensored

AI Model Lab может находить модели в двух каталогах на локальном диске:

- /mnt/Games/AI/Censored
- /mnt/Games/AI/Uncensored

Также проверяются существующий model_root и пути из model_roots (если они заданы в models.json). Каталоги, отсутствующие или не смонтированные, выводятся как предупреждение и **не приводят к удалению профилей**.

## Через интерфейс KDE

1. Смонтируй диск /mnt/Games.
2. Запусти AI Model Lab. Перейди во вкладку «Модели» и нажми «🔎 Найти GGUF».
3. Просмотри найденные новые профили и предупреждения. Нажми «Да» для импорта.
4. Перейди в «Настройки» → выбери новую модель и проверь параметры перед первым запуском.

Импорт не запускает модели, не удаляет существующие профили, не перемещает и не скачивает веса. Файлы mmproj, не являющиеся основными LLM-весами, не создают отдельных профилей. У моделей, разбитых на части, выбирается первый GGUF-файл; остальные части должны находиться рядом.

Для новых профилей используется **абсолютный путь** к GGUF, поэтому каталог Uncensored работает без изменения прежнего model_root. Существующие профили (включая настройки 128K-контекста, sampling и дополнительных аргументов) не изменяются. Повторный импорт не должен создавать дубликатов для уже привязанных файлов.

## Через терминал Fish / Bash

Сначала посмотри план (без изменений файлов):

    python3 ~/AI/AI-Model-Lab/model_catalog.py

Если список верен, закрой графическое приложение и выполни:

    python3 ~/AI/AI-Model-Lab/model_catalog.py --apply

Можно задать другие каталоги и путь конфигурации:

    python3 ~/AI/AI-Model-Lab/model_catalog.py --root /путь/А --root /путь/Б --config ~/AI/AI-Model-Lab/models.json

Без --apply файл models.json не изменяется. С --apply создаётся резервная копия в data/backups/models_import_*.json, затем конфигурация записывается атомарно. Старые резервные копии не удаляются.

## Настройки и ограничения

- Новые модели получают контекст 32768, ngl=99, parallel=1, no_kv_offload=true, KV-кэш q8_0, batch=1024 и ubatch=256. Эти параметры **консервативная отправная точка, а не гарантия запуска на GPU**.
- Порты новых профилей выделяются из диапазона 8081–8999, с проверкой уже используемых профилями и локальными сервисами. Уже настроенные порты не меняются.
- Для кодовых моделей по имени выбирается OpenCode, для остальных — Pi. Глобальные конфигурации Pi и OpenCode импорт не переписывает.
- Для Vision-моделей, если найден единственный mmproj в той же папке семейства, путь заполняется автоматически. Иначе выводится предупреждение: проверь mmproj вручную.
- Ни наличие GGUF, ни наличие mmproj не доказывает совместимость конкретной модели с установленным llama.cpp, корректность шаблона чата или достаточность VRAM. Реальный запуск и скорость проверяются отдельно.
- Особенно внимательно проверь большие MoE, варианты Unsloth/Huihui, флаги reasoning и длину контекста; одинаковые параметры не обязательно оптимальны для всех моделей.

В репозиторий не должны попадать приватные models.json, настройки, веса GGUF и лог-файлы. Импорт работает локально.
