# Pi Office Bridge — подключение Pi к Agent Office

Наблюдатель **Pi → Agent Office** передаёт реальные события Pi в локальный inbox
`~/.hermes/pixel-office/inbox/`. Agent Office сам читает inbox и показывает
активные сессии в пиксельном офисе. Отдельный сетевой сервер мосту не нужен.

## Что отображается

- Создание/загрузка сессии Pi → `Idle`.
- Работа модели → `Thinking`.
- Начало и завершение вызова инструмента → активность инструмента.
- Запрос пользовательского ввода → ожидание, окончание диалога → продолжение.
- Окончательное завершение хода (`agent_settled`) → `Idle`.
- Закрытие или переключение сессии (`session_shutdown`) → выход из офиса.

**Не передаются:** промпты, ответы, пути/аргументы инструментов, содержимое
файлов и ключи авторизации. В событиях есть только идентификатор сессии,
тип события, имя инструмента, ID вызова, статус, время и PID. Статистика токенов
и роли девятиагентной команды этим наблюдателем не выдумываются.

## Из AI Model Lab

Установи обновление (`bash ./install.sh` из корня Git-репозитория).
Открой нужную запущенную модель через **«Открыть в Pi»**. Приложение добавляет
`--extension <путь>/extensions/pi-office-bridge.js` к команде Pi, если мост
ещё не установлен в каталоге расширений этой конфигурации.

Это работает и для изолированного Pi-профиля на портах 8081/8082.
Глобальные настройки Pi, права агентов и Android-бенчмарки не изменяются.

## Для обычного `pi` в Konsole / Fish

Чтобы все обычные Pi-сессии также появлялись в офисе, **явно подключи**
глобальное расширение один раз:

```fish
python3 ~/AI/AI-Model-Lab/pi_bridge_manager.py --status
python3 ~/AI/AI-Model-Lab/pi_bridge_manager.py --install
```

Перезапусти Pi и выполни настоящую задачу. Для отключения:

```fish
python3 ~/AI/AI-Model-Lab/pi_bridge_manager.py --uninstall
```

Менеджер создаёт только символьную ссылку в `~/.pi/agent/extensions`.
Другие файлы не заменяет, `models.json` не меняет. Удаляет только свою ссылку.

## Проверка

1. Открой Agent Office на `http://127.0.0.1:8113` (или по своему адресу).
2. Запусти Pi с подключённым мостом. В офисе появится сессия Pi.
3. Отправь короткий запрос: появится `Thinking`, после ответа — `Idle`.
4. В `~/.hermes/pixel-office/inbox` новые события могут исчезать сразу после
   обработки офисом — пустая очередь при работающем офисе нормальна.

Если Pi не появился, проверь `PI_CODING_AGENT_DIR`, `HERMES_HOME`, загрузку
расширения Pi и права доступа к inbox. Параметр `--no-extensions` намеренно
отключает мост (включая защищённые Android-бенчмарки). Если офис выключен,
события сохраняются в файловой очереди. При сбое записи Pi продолжает работать.

**Безопасность:** расширения Pi выполняются с правами пользователя. Проверяй
исходник перед включением. Мост не создаёт фиктивных агентов и не открывает
доступ к чтению, записи файлов, терминалу или сети.
