# Установка и использование (русский)

**Русский** · [English](INSTALL.md) · [Главная](README_RU.md)

## 1. Подготовка системы

Основная проверяемая платформа — **CachyOS / Arch Linux и KDE Plasma**. Нужны Linux, Python 3.11+ и установленный `llama-server`. Для функций NVIDIA — драйвер/CUDA и рабочий `nvidia-smi`.

```fish
sudo pacman -Syu pyside6
python3 -c 'from PySide6.QtWidgets import QApplication; print("PySide6 OK")'
```

Установи/собери [llama.cpp](https://github.com/ggml-org/llama.cpp) по инструкции разработчиков; при использовании NVIDIA — с поддержкой CUDA. В репозиторий не входят ни `llama-server`, ни GGUF-веса моделей.

## 2. Установка AI Model Lab

Открой терминал в папке клонированного репозитория (или распакованного исходного архива):

```fish
python3 release_preflight.py
python3 -m unittest discover -s tests -v
bash ./install.sh
~/.local/bin/ai-model-lab
```

Путь по умолчанию: `~/AI/AI-Model-Lab`. Для другого каталога: `env AI_MODEL_LAB_HOME=/путь/к/папке bash ./install.sh`. При первой установке `models.json` и `settings.json` создаются из `*.example.json`; при обновлении существующие профили, отчёты и логи сохраняются.

## 3. Настройка моделей

На вкладке **«Модели»** выбери профиль и открой **«Изменить»**. Укажи реальный GGUF-файл, контекст, GPU и порт API. Демонстрационные профили не готовы к работе без собственных путей: каталога `~/AI/models` может не существовать.

Путь к бинарнику `llama-server` задаётся ключом `server_bin` в установленном файле **`~/AI/AI-Model-Lab/models.json`** (либо в другом каталоге установки, если он был изменён). Текстовое редактирование конфигурации выполняй при полностью закрытом GUI, предварительно сохранив резервную копию.

## 4. Две или больше видеокарт

Узнать UUID устройств:

```fish
nvidia-smi --query-gpu=index,name,uuid,memory.total --format=csv
```

В настройках модели выбери UUID нужной видеокарты (для двух одинаковых RTX так надёжнее, чем индекс) и свободный порт. Пример: Blend Q4 на первой GPU — `8080`; клонированная Blend Q4 на второй GPU — `8081`. Один GGUF может использоваться обоими профилями, но каждое приложение загружает свой экземпляр весов и расходует собственную VRAM. Несколько моделей на одном GPU тоже допустимы при достаточных ресурсах.

## 5. Открытие в Pi / OpenCode и дополнительные сервисы

[Pi](https://github.com/badlogic/pi-mono), [OpenCode](https://opencode.ai/), [Open WebUI](https://github.com/open-webui/open-webui), Agent Office и ComfyUI — **внешние программы**, их нужно устанавливать отдельно.

Рядом с кнопкой **«Открыть в»** выбери Pi или OpenCode. Это только меняет сохранённое предпочтение для модели. Для запуска клиента сначала запусти модель, дождись готовности API и затем нажми **«Открыть в»**. Выбранному клиенту передаются alias и порт работающего сервера, глобальные файлы конфигурации не перезаписываются. Если нужно, локальная конфигурация Pi сохраняется в `data/clients/`.

Open WebUI обычно открывается по `http://127.0.0.1:3000`. Команды запуска/остановки через GUI предполагают настроенную пользовательскую службу systemd; если Open WebUI установлен по-другому, понадобится отдельная настройка. Каталоги Agent Office и ComfyUI указываются в общих настройках.

## 6. Тесты, отчёты и логи

На вкладке **«Тесты»** доступны скорость API, числовые задачи, синтетический длинный контекст и примерные задания по Android. Отчёты сохраняются в `data/reports`, логи — в `data/logs`. Подробнее — [Бенчмарки](BENCHMARKS.md). Для агентных Android-тестов может потребоваться установленный Pi и согласованный контекст/порт модели.

Внимание: ограничение списка доступных инструментов Pi **не равно файловой песочнице ОС**. Приватные проекты нужно защищать отдельно. Промпты из старого закрытого проекта не публикуются; сравнивать их результаты с новыми демонстрационными тестами напрямую нельзя.

## 7. Частые ошибки

- **Не импортируется PySide6:** установи `pyside6` через `pacman` и проверь Python-командой выше.
- **Не найден llama-server:** укажи путь к собранному бинарнику в `server_bin`.
- **Не найден GGUF:** укажи конкретный файл. Шаблон, совпадающий с несколькими GGUF, неоднозначен.
- **Порт занят:** двум одновременно работающим серверам требуются разные порты; чужие процессы автоматически не останавливаются.
- **Не та GPU:** проверь `nvidia-smi` и UUID. «Авто» не гарантирует использование только одной карты.
- **Не хватает VRAM:** уменьши контекст/число GPU-слоёв или выбери меньшую модель — это может снизить скорость.
- **Pi или OpenCode не открывается:** установи клиент, проверь его `PATH` и предварительно запусти саму модель.
- **Приложение падает:** запусти `~/.local/bin/ai-model-lab` из терминала и проверь `data/logs`. Не публикуй логи с ключами и личными путями без предварительной очистки.

## 8. Обновление и удаление

Для обновления повтори `bash ./install.sh` из папки новой версии. Код программы заменится, а `models.json`, `settings.json`, `data/` сохранятся. Установщик также создаёт резервную копию части прежнего программного кода. Перед удалением программы останови управляемые сервисы, сохрани нужные профили и отчёты, затем вручную удали каталог приложения и ярлык KDE.
