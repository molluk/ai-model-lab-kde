# Папки моделей, контекстное меню, избранное и фильтры

Вкладка **Модели** показывает все профили в раскрываемых виртуальных папках:
`Censored`, `Uncensored`, `Без папки` и собственных пользовательских.
Папки формируются из путей GGUF или задаются вручную. **Файлы GGUF не
переносятся**, настройка модели и её порт не меняются при организации.

## Управление папками через ПКМ

- **ПКМ на папке**: «Создать папку», «Переименовать папку»,
  «Удалить папку», «Развернуть/свернуть».
- **ПКМ на модели**: «★ В избранное» / «☆ Убрать из избранного»,
  «Переместить в папку» (включая «Без папки»), «Создать папку»,
  «Изменить», «Клонировать», «Удалить».
- **ПКМ на пустом месте дерева**: «Создать папку».
- **Перетаскивание ЛКМ**: зажми строку модели и отпусти на строке
  папки, чтобы переместить профиль в неё. Автоматически срабатывает
  сохранение `models.json`, но не перенос файла на диске.
- Удаление папки **не удаляет** модели. Содержащиеся профили переводятся
  в группу «Без папки» и сохраняют настройки.
- Избранная модель помечается **золотой ★** слева от названия.
  Состояние хранится в `models.json` как `favorite: true/false`.

Изменения производятся через проверку текущего `models.json`,
атомарную запись и отдельную резервную копию в `data/backups/`.
Если файл изменён другой программой после открытия окна, сохранение
блокируется, а не перезаписывает чужие правки.

## Фильтр каждого столбца по нажатию

Клик по **заголовку** любого из семи столбцов открывает небольшую
панель с поиском по значениям и флажками. Можно выбрать несколько
значений и нажать «Применить». Пункты «Все», «Ничего» и «Сбросить»
дают быстрый контроль фильтра. Поля поиска над таблицей отсутствуют.

- Одновременно действуют фильтры разных столбцов (логическое **И**).
- «↑ Сортировать» / «↓ Сортировать» сортируют выбранный столбец;
  контекст, порт, PID сортируются по числам.
- Фильтры работают на уровне моделей, не скрывают их из `models.json`.
- Фильтр по статусу обновляется вместе с состоянием серверов.
- Активный фильтр отмечается символом **●** в заголовке столбца.

## Проверки и ограничения

- CI: Python 3.11/3.12 unit-тесты, тест реальной упаковки
  `install.sh` и PySide6 offscreen тест создания окна/папок/фильтров.
- При вводе новых данных в `models.json` или импорте новых моделей
  дерево можно пересоздать без изменения существующих избранных.
- Вся разработка — в `feature/virtual-model-folders-column-filters`.
  Ветки `main` и `dev` не изменяются автоматически.
- Настройки контекста, GPU, batch и KV-кэша не зависят от папок и
  избранного. Их оптимизация — отдельная задача с проверкой VRAM,
  tokens/sec и стабильности запуска на RTX 2080 Ti 22 ГБ.
