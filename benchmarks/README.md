# Встроенные испытания AI Model Lab v3

- API speed: 256/512 выходных токенов, скорость от полного времени, VRAM, GPU, энергия.
- QA: 3 небольших задачи с детерминированными числовыми ответами. Это не оценка разработки Android.
- Context recall: синтетические контрольные факты на 5/50/95% текста, грубая оценка размера без абсолютной гарантии числа токенов.
- Android P1/P2: новый набор заданий v3 (отдельный SHA256!), Pi read/grep/find/ls, жёсткий бюджет вызовов, журнал Pi, телеметрия, отчёты.

ВАЖНО: новые P1/P2 не совпадают бит-в-бит со старыми v3 промптами и не являются прямым рейтингом прежних результатов.
Pi инструменты могут получить доступ к файлам вне проекта, несмотря на ограничения промпта. Перед использованием на закрытых исходниках нужна ОС-песочница.

Всё ПО лаборатории и результаты живут в каталоге ~/AI/AI-Model-Lab. GGUF и установленные приложения остаются в своих папках — не копируем десятки гигабайт моделей.
