# AI Model Lab KDE v3 — самостоятельная локальная лаборатория

**Один каталог**: `~/AI/AI-Model-Lab`. В нём код GUI, профили GGUF, встроенные тесты, Pi-расширение, результаты (`data/reports/`), журналы (`data/logs/`) и файл состояния процессов (`data/`). Старые `ai-benchmark-kit`, `ai-model-lab-v2`, готовые загруженные тесты и Fish-лаунчеры не используются. **GGUF не копируются:** весят десятки ГБ и остаются по прежним путям. Pi, llama.cpp, Open WebUI, Agent Office, ComfyUI — уже установленные программы; установка самих внешних программ не входит в пакет.

## Установка CachyOS (KDE Plasma)

1. Распаковать архив и открыть терминал в папке `AI-Model-Lab-KDE-v3`.
2. Проверить Qt: `python3 -c 'import PySide6'`.
3. Если отсутствует: `sudo pacman -S python-pyside6` (эта команда устанавливает Qt-связку из репозитория, **скрипт установки ничего из сети не скачивает**).
4. `bash ./install.sh`
5. `~/.local/bin/ai-model-lab` или ярлык «AI Model Lab — KDE» из меню KDE/рабочего стола.

При обновлении инсталлятор **не перезаписывает** уже существующие `models.json`, `settings.json` и `data/`, но обновляет код приложения и встроенные промпты/guard. Старые приложения и ярлыки остаются на месте; никаких массовых `pkill`.

## Основное окно

- Вкладка **Модели**: все семь известных моделей, контекст, краткое назначение, путь GGUF, запуск/остановка, открытие WebUI и Agent Office.
- Вкладка **Управление**: отдельный запуск и остановка llama.cpp, Open WebUI, Agent Office, ComfyUI; «остановить все» с подтверждением. Останавливаются только проверенные процессы, запущенные AI Model Lab; WebUI управляется только через `systemctl --user open-webui.service`.
- Вкладка **Тесты**: speed 256/512, QA 3 задачи, длинный контекст около 8K/32K, агентные Android P1/P2 со сбором телеметрии и ограничителем Pi.
- Вкладка **Отчёты**: просмотр истории, JSON, сравнение двух запусков с проверкой совпадения SHA-256 промптов.
- Вкладка **Настройки**: параметры служб, пути к офису/ComfyUI/Android-проекту и редактирование профилей моделей.
- В верхней части — графики загрузки GPU, VRAM, RAM, температур и энергопотребления NVIDIA по nvidia-smi.

## Параметры и особенности

Профили `blend-q4`, `qwen38-27b`, `coder-30b` имеют `-c 131072`, `-np 1`, `-ngl 99`, `--no-kv-offload`, KV `q8_0`, `--jinja`, `--metrics`, localhost:8080. Qwen3.8/Blend дополнительно получают `enable_thinking:false`. Для остальных четырёх профилей текущие консервативные контексты 32K/96K, как в прежних настройках, без утверждений об их проверенности.

Если порт 8080 занят, новая модель **не убивает работающую**. Остановка и переключение потребуют ручного выбора. При закрытии окна сервера остаются работающими в фоне. Старт/стоп офисного сервера управляет только запуском AI Lab; старый офис, стартовавший через прежний `start-agent-office.sh`, не перехватывается.

## Встроенные тесты

`bench.py` реализован заново, использует stdlib Python, Pi и уже запущенный llama.cpp. Android-проект **читается, но не изменяется**. Каждая задача создаёт собственную папку в `data/reports`, включая `summary.json`, `summary.md`, `telemetry.csv`, `overview.csv`, а для Android также `pi-events.jsonl`, `pi-stderr.log`, `final_answer.md`. Отчёты не хранятся в директории Android-проекта.

**P1 и P2 в этом пакете являются новой версией промптов.** Их результаты нельзя напрямую сравнивать по качеству с архивными LP-01A/P1 v3 без поправки на изменение задания. Контрольные суммы новых промптов автоматически записываются в summary.json.

**Внимание к безопасности:** флаги Pi `--tools read,grep,find,ls` не дают инструментов записи, но **не ограничивают** доступ модели к секретам или файлам вне проекта на уровне ОС. Код сканирования исходников также может содержать чувствительные данные. Не используй на закрытых репозиториях без файловой песочницы; записи Pi-JSONL с исходным кодом хранятся приватно (каталоги 0700, JSON 0600).

**Статус «completed» не гарантирует правильности результата.** Качество Android call chain требует эталонного анализа и независимой проверки ссылок на строки; автоматическая оценка пока не претендует на достоверный балл.

## Прямой запуск бенчмарков (если нужно)

```fish
cd ~/AI/AI-Model-Lab
python3 bench.py --kind speed --model blend-q4 --output-tokens 256
python3 bench.py --kind qa --model blend-q4
python3 bench.py --kind p1 --model blend-q4 --project '/path/to/android/project' --budget 24 --timeout 1800
```

## Проверка исходников пакета

```fish
cd ~/AI/AI-Model-Lab
python3 -m unittest discover -s tests -v
```

Реальные загрузки моделей и сервисов в твоём CachyOS не проверялись; код проверен синтаксически, self-test и логикой изолированных тестов. Если увидишь ошибку, пришли её текст и файл журнала из `data/logs/`.
