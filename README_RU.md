# AI Model Lab v2.1 — CachyOS / Fish / KDE

Обновление AI Model Lab v2 с **описаниями назначения моделей**, двумя общими разделами **«Тесты»** и **«Управление»** и раздельным запуском/остановкой сервисов. Используется Python 3 (только стандартная библиотека), llama.cpp, Pi и уже существующие пользовательские скрипты. Никаких сетевых установок, изменений Android-проектов или изменений `~/.pi/agent/models.json`.

## Установка или обновление v2

Распакуй ZIP, открой Fish в каталоге `AI-Model-Lab-v2.1` и запусти:

```fish
bash ./install.sh
~/.local/bin/ai-model-lab-v2 doctor
~/.local/bin/ai-model-lab-v2 menu
```

Устанавливается **поверх v2** по тем же путям `~/.local/share/ai-model-lab-v2/` и `~/.local/bin/ai-model-lab-v2`. `models.json` **не перезаписывается**, поэтому сохранённые личные пути и настройки остаются прежними. Даже со старым v2-файлом `models.json` подписи назначений отображаются по встроенным значениям; для собственного назначения можно добавить ключ `purpose` в соответствующий профиль. Старые скрипты и desktop-файлы `AI-*.desktop` не удаляются.

Создаются **12 ярлыков KDE**: 7 моделей, основной менеджер, два отдельных ярлыка **«AI Lab — Тесты»** и **«AI Lab — Управление»**, «Статус» и «Остановить всё». Названия модельных ярлыков и их `Comment=` включают краткое назначение.

## ⚙ Управление сервисами

Меню `m` либо команда `ai-model-lab-v2 manage`:

- Запустить llama.cpp с выбранной моделью или **переключить** текущую управляемую модель (с подтверждением перед остановкой).
- Остановить **только** управляемый llama.cpp.
- Отдельно запустить или остановить `open-webui.service` (порт 3000).
- Отдельно запустить или остановить Agent Office через имеющийся `~/.local/bin/start-agent-office.sh` и его PID-файл.
- Отдельно запустить или остановить ComfyUI (порт 8188), если он был запущен новой программой.
- Посмотреть статус, параметры GPU, журнал llama.cpp или остановить все известные **управляемые** AI-сервисы (только после подтверждения).
- Отдельно остановить **старые** экземпляры llama-server после показа PID и ввода специальной фразы подтверждения.

Операции остановки llama.cpp не используют `pkill -f`; проверяется PID, исполняемый файл и момент запуска. Сторонние серверы на занятом порту **не убиваются**. Остановка Open WebUI касается только его известного systemd user-service. Если офис запущен в другом месте или ComfyUI был запущен старым скриптом, программа не обещает остановить неподтверждённый процесс. Pi/OpenCode автоматически не закрываются. Рабочий Android-проект не изменяется.

## 🧪 Тесты

Меню `t` либо команда `ai-model-lab-v2 tests`:

1. Быстрый API speed-test с лимитом 256 выходных токенов.
2. Расширенный API speed-test с лимитом 512 токенов.
3. Android LP-01A/P1 (900 секунд, существующий Fish-лаунчер и Pi).
4. Android LP-01A/P2 (900 секунд, существующий Fish-лаунчер и Pi).
5. Показ последних отчётов из `/home/USER/AI/benchmark-kit/benchmarks`.
6. Сравнение выбранных отчётов через `ai-benchmark.py compare`; перед сравнением требуется совпадение SHA-256 промпта.
7. Диагностика моделей, конфигурации Pi, GPU, RAM и статусов сервисов.

Полноценные Android-бенчмарки используют **только существующий** `run-LP-01A-comparison.fish`, который вызывает `ai-benchmark.py`, проверяет базовые SHA-256, лимит вызовов инструментов и отпечаток исходников. Для исторических P1/P2 поддерживаются только `blend-q4`, `qwen38-27b`, `coder-30b` — не запускай ими другие модели без отдельного benchmark-профиля. Успешный exit code скрипта не гарантирует правильность кода; проверяй `summary.json`.

Перед Android-бенчмарком новая панель проверяет, что в Pi `contextWindow` соответствует фактическому `n_ctx` сервера. Нельзя выполнять тест без запуска подходящей модели. Тест требует отдельного подтверждения. **read/grep/find/ls не являются ОС-песочницей:** секреты в репозитории потенциально доступны агенту. Для постоянной эксплуатации нужна изоляция файловой системы.

Speed-test использует локальный API `127.0.0.1:8080` и сохраняет JSON в `~/.local/state/ai-model-lab-v2/benchmarks/`. Скорость `output/wall` включает prompt prefill и не равна чистой скорости декодирования. Для воспроизводимых сравнений качества продолжай использовать `ai-benchmark.py`.

## Команды

```fish
~/.local/bin/ai-model-lab-v2 menu
~/.local/bin/ai-model-lab-v2 tests
~/.local/bin/ai-model-lab-v2 manage
~/.local/bin/ai-model-lab-v2 start blend-q4 --menu
~/.local/bin/ai-model-lab-v2 doctor
~/.local/bin/ai-model-lab-v2 status
~/.local/bin/ai-model-lab-v2 speed
~/.local/bin/ai-model-lab-v2 discover
~/.local/bin/ai-model-lab-v2 stop
~/.local/bin/ai-model-lab-v2 stop-all --ask
```

Если Android-бенчмарк перенесён в другую папку, путь можно указать через переменную `AI_BENCHMARK_LAB`. Для модели с нестандартным путём GGUF исправь `models.json` или переменную `AI_LAB_GGUF_<ALIAS>`. Не удаляй `pi`, `hf`, `tiny-agents`, `open-webui` — это точки входа других установленных приложений.

## Проверки

На тестовом окружении проверены синтаксис Python/Bash, маршрутизация пунктов меню, отдельная остановка WebUI без затрагивания llama/Agent Office, запрет неподдерживаемых benchmark-алиасов, запрет бенчмарка при несовпадении контекста и генерация команд запуска всех семи моделей. **Запуск реальных серверов и тесты на твоём CachyOS этим комплектом ещё не проводились.**
